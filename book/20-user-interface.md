# 20. ממשק משתמש

ה-GUI שתכננתי בנוי סביב חלון יחיד שמציג את כל המידע
הקריטי בו-זמנית, בלי להפיץ את המשתמש בין חלונות מקבילים.
הטבלה הראשית, לוג האירועים החי, ושורת הסטטוס נראים תמיד
— הכל ב-`JFrame` אחד עם `JSplitPane`.

הבחירות העיצוביות המרכזיות:

**Defaults שעובדים מהקופסה**: `Rarest First` +
`Tit-for-Tat` הם ברירת המחדל של ה-Combos. משתמש שלא מבין
באלגוריתמים פשוט לוחץ Add Torrent → בוחר קובץ → בוחר
תיקייה → ההורדה מתחילה.

**שקיפות בלי הצפה**: ה-Event Log חשוף לחלוטין; משתמש
שמתעניין רואה את כל הפעולות הפנימיות (חיבורי peers, פיסים
שאומתו, באנים). משתמש נינוח יכול להתעלם ממנו — הוא נמצא
ב-30% התחתונים של ה-SplitPane וניתן להקטין אותו.

**אישור הרסני בלבד**: `JOptionPane.showConfirmDialog`
מופיע רק לפני פעולות לא הפיכות (Cancel, Clear History).
פעולות הפיכות (Pause/Resume) לא דורשות אישור — לחיצה
אחת מספיקה.

**שקט ב-error path**: שגיאות שלא ביוזמת המשתמש (כשל
pause/resume שכנראה ייפתר ב-polling הבא) לא מציגות popup;
רק שגיאות יזומות (Start Download) מציגות popup. הגישה
מפחיתה הפרעות מיותרות.

**רספונסיביות**: ה-UI לעולם לא נחסם. ה-
`ScheduledExecutorService` מתזמן עדכון כל 500ms אבל
ה-task עצמו רק קורא ל-`SwingUtilities.invokeLater` ל-
EDT. כל קריאת HTTP נעטפת ב-`new Thread(...).start()` כדי
שלא לחסום את ה-EDT. עדכוני טבלה רצים תמיד דרך
`invokeLater`. גם בעת קריאת `GET /history` ארוכה או
`POST /torrents` שנתקעת ב-tracker איטי, החלון נשאר
רספונסיבי — אפשר לגרור, להזיז, ולחזור עליו.

**התנהגות בעת ניתוק שרת**: אם ה-Python Engine נופל
באמצע סשן, `apiService.getStatus()` יזרוק חריגה.
`refreshStatus` תופסת אותה שקטה (`catch (Exception e)
{}`) — הנתונים בטבלה לא ירוקנו, נשארים מהריענון האחרון.
בריענון הבא, אם השרת חזר — הנתונים מתעדכנים שוב כרגיל.
זוהי בחירה מודעת: המצב הויזואלי האחרון הוא הטוב ביותר
זמין, אין סיבה להפחיד את המשתמש עם "Server disconnected"
שעלול להיות חולף.

## בחירות חזותיות

הממשק מסתמך על ה-`UIManager.getSystemLookAndFeelClassName()`
כדי להיראות כמו אפליקציה נטיבית בכל OS. הצבעים המוגדרים
מפורשות הם רק שניים: `Color(60, 120, 200)` (כחול) ל-
ProgressBar בזמן הורדה, ו-`Color(50, 150, 50)` (ירוק)
כשה-progress הגיע ל-100%. ה-popups של `JOptionPane`
משתמשים באייקונים הסטנדרטיים של Swing (i כחול, X אדום,
? סגול).

הפונט: ברירת המחדל של ה-OS לרכיבים, ו-`Font.MONOSPACED, 12`
ל-Event Log כדי שחותמות זמן ושמות peers (IPv4) יסתדרו
לפי עמודות. אין אייקונים מותאמים — להימנע מ-overhead של
ניהול resource files ולשמור על תאימות בין OSים.

## תמיכה ב-RTL

כותרת החלון בעברית (`"מערכת שיתוף קבצים מבוזרת בסגנון
BitTorrent"`) — Swing על Java 11+ תומך RTL בכותרת חלון.
תוכן הטבלה והלוג הוא LTR טכני כי הוא כולל IDs, IPs,
שמות אלגוריתמים — נתונים אנגלית-טכניים. תרגום מלא לעברית
+ RTL בכל ה-content הוא שיפור עתידי (פרק 26).
