# 8. ניתוח חלופות מערכתי

לפני שבחרתי בארכיטקטורה הסופית, בחנתי שלוש חלופות
ארכיטקטוניות. הנה ה-SWOT לכל אחת.

## חלופה A: Client-Server קלאסי (שרת HTTP מרכזי)

הקובץ מאוחסן על שרת מרכזי, וכל לקוח מוריד אותו ישירות
דרך HTTP/HTTPS.

| Strengths | פשטות מימוש; HTTP מוכר ובוגר; קל לבדוק עם `curl` |
| Weaknesses | עומס גבוה על השרת; bandwidth מצרפי יקר; single point of failure |
| Opportunities | שילוב CDN להפצה גלובלית; HTTPS לאבטחה מובנית |
| Threats | אם השרת נופל, אף אחד לא מוריד; תוקפי DDoS יכולים להפיל הכל |

**לא בחרתי בזה** כי הוא לא עונה על המטרה האלגוריתמית
של הפרויקט — אין כאן בעיה אלגוריתמית מעניינת. גם בידוד
שגיאות חלש.

## חלופה B: P2P מבוזר (BitTorrent)

כל לקוח הוא גם seeder וגם leecher. ה-bandwidth של ההורדה
מתחלק בין כל ה-peers ב-swarm. tracker מספק רשימת peers
ראשונית בלבד.

| Strengths | חוסן גבוה (אין SPOF); bandwidth מתחלק; ניתן לבדוק על swarm קיים; אלגוריתמיקה עשירה |
| Weaknesses | מורכבות מימוש גבוהה; דרוש לטפל ב-peers זדוניים; NAT traversal מסובך |
| Opportunities | DHT/PEX להוסיף עצמאות מ-tracker; MSE/PE לאנטי-DPI; BEP-52 ל-SHA-256 |
| Threats | swarms קטנים פחות יעילים; trackers ציבוריים יכולים להיחסם |

**בחרתי בזה**. הוא היחיד שמספק את העושר האלגוריתמי
שדורש המחוון.

## חלופה C: רשת היברידית (P2P + CDN seed)

עירוב — שרת CDN משמש כ-seeder ראשי תמיד-זמין, וגם peers
אחרים יכולים לתרום. השילוב הזה משמש בפועל ע"י חברות
משחקים (Blizzard, Riot) שצריכות הפצה מהירה של עדכונים.

| Strengths | מהירות התחלתית מובטחת (CDN); חוסן גבוה (P2P) |
| Weaknesses | מורכבות הפעלה כפולה; עלות CDN; דרוש שילוב של שני פרוטוקולים |
| Opportunities | מסחור פוטנציאלי; ניתן לכוון את התמהיל לפי עומס |
| Threats | תלות בספק CDN; קוד מורכב לתחזוקה |

**לא בחרתי בזה** כי הוא יקר ומורכב מבחינה תפעולית, ומפסיק
להיות "פרויקט אקדמי לימודי".

## הכרעה

חלופה B (BitTorrent טהור) נבחרה. הסיבות:

1. **המחוון דורש בעיה אלגוריתמית** — חלופה A לא מספקת
   את זה.
2. **המחוון דורש שתי שפות + שפה מהודרת** — BitTorrent
   מתאים מצוין לפיצול Python (פרוטוקול) + Java (UI).
3. **המחוון דורש אבטחת מידע** — BitTorrent מציע נושאים
   אבטחתיים עשירים (אימות SHA-1, מערכת מוניטין נגד
   peers זדוניים, פרטיות מול tracker).
4. **אפשרות לניסויים אמפיריים** — אפשר להריץ את אותו
   קובץ עם שני אלגוריתמים שונים ולמדוד את ההפרש.
