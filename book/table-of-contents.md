## מבנה מפורט של כל פרק (מספור לפי נוהל ההגשה)

### פרק 1 – הצעת הפרויקט שאושרה על ידי משרד החינוך
שילוב/סריקה של מסמך ההצעה החתום (`הצעת פרוייקט - אדם זבולון 329441273 V2.2.pdf`), כולל פרטי המגיש, תיאור הנושא, הגדרת הבעיה האלגוריתמית, רקע תיאורטי בהצעה, ניתוח החלופות, אלגוריתמיקה, פרוטוקולי תקשורת, אבטחה, פיתוחים עתידיים, מסד נתונים, לוח זמנים, רשימת מאמרים, מילון מושגים וחתימות.

### פרק 2 – תקציר / מבוא
- 2.1 הרקע לפרויקט
- 2.2 תהליך המחקר (כולל מחקר מקדים / עבודת שטח אם רלוונטי)
- 2.3 סקירת ספרות
- 2.4 אתגרים מרכזיים
  - 2.4.1 הבעיה שהתלמיד התמודד איתה
  - 2.4.2 הסיבות לבחירת הנושא
  - 2.4.3 מוטיבציה לעבודה
  - 2.4.4 הצורך שעליו עונה הפרויקט – איזה פתרון הוא נותן
  - 2.4.5 הצגת פתרונות לבעיה (אלו שנבחנו במחקר המקדים)

### פרק 3 – מטרות / יעדים
מטרות-על, יעדים מדידים, יעדי משנה.

### פרק 4 – אתגרים
אתגרים טכניים, אלגוריתמיים, רשתיים, ארכיטקטוניים ואתגרי אינטגרציה בין שפות.

### פרק 5 – מדדי הצלחה למערכת
KPIs כמותיים (זמן הורדה, אחוז השלמה, אחוז verification, יציבות), KPIs איכותיים (חוויית משתמש, יכולת שחזור מצב, אבטחה).

### פרק 6 – רקע תיאורטי / ספרות מקצועית
- 6.1 מושגים עיקריים בתחום הדעת של הבעיה (P2P, BitTorrent, swarm, seeder/leecher, info_hash)
- 6.2 נושאים רלוונטיים בתחום הדעת של הבעיה (אלגוריתמי שיתוף קבצים, פרוטוקולי תקשורת)
- 6.3 סקירה מקצועית של הבעיה בעולם
- 6.4 נושאים רלוונטיים במדעי המחשב בהקשר לבעיה (תורת המשחקים, מבני נתונים, רשתות, מערכות הפעלה / עיבוד מקבילי)

### פרק 7 – תיאור פתרונות קיימים לבעיה
qBittorrent, Transmission, libtorrent, Deluge, פתרונות ענן (HTTP/CDN/IPFS), פתרונות BitTorrent v2 ו-WebTorrent.

### פרק 8 – ניתוח חלופות מערכתי
חלופה A: Client-Server קלאסי · חלופה B: P2P מבוזר (BitTorrent) · חלופה C: רשת היברידית / CDN. ניתוח SWOT לכל חלופה.

### פרק 9 – תיאור החלופה הנבחרת
הצדקת בחירת ה-P2P BitTorrent, היתרונות הספציפיים לבעיה ולמגבלות הפרויקט.

### פרק 10 – אפיון המערכת שהוגדרה / מוצעת
- 10.1 ניתוח דרישות המערכת (פונקציונליות ולא-פונקציונליות)
- 10.2 מודול המערכת
- 10.3 אפיון פונקציונלי
- 10.4 ביצועים עיקריים
- 10.5 אילוצים

### פרק 11 – תיאור הארכיטקטורה
- 11.1 ארכיטקטורה Top-Down Level Design
- 11.2 תיאור הרכיבים בפתרון (DB, שרת תקשורת, שרת יישום, לקוח)
- 11.3 תיאור תהליכי מערכת ההפעלה (asyncio event loop, threading, ThreadPoolExecutor)
- 11.4 ארכיטקטורת רשת
- 11.5 תיאור API בארכיטקטורה (REST API מקומי)
- 11.6 תיאור פרוטוקולי התקשורת (HTTP/REST, HTTP Tracker, BEP-3 Peer Wire Protocol)
- 11.7 שרת-לקוח

### פרק 12 – תיאור תהליכי אבטחת מידע במערכת
- 12.1 תיאור התקיפה או ההגנה (וקטורי איום, מודל איום, ניתוח שכבת אפליקציה ושכבת תעבורה)
- 12.2 תיאור הצפנות (SHA-1 ל-piece verification, ניתוח SWOT לאלגוריתמי הצפנה, פרטיות מול ה-Tracker)

### פרק 13 – (לא רלוונטי לפרויקט זה)
נימוק קצר: הפרויקט אינו עוסק בלמידת מכונה ולכן סעיפים 13.1–13.5 בנוהל אינם נדרשים. נספח קצר בקובץ ייעודי.

### פרק 14 – תיאור התוכנה
- 14.1 פירוט API (כל endpoint, פרמטרים, תגובה)
- 14.2 סביבת עבודה (Python 3.8+, JDK 11+, OS תמיכה, רשת)
- 14.3 שפות תכנות (נימוק בחירת Python ו-Java)

### פרק 15 – ניתוח ותרשים Use Cases / UML של המערכת המוצעת
- 15.1 תיאור ה-UC העיקריים (אלגוריתם ראשי + אלגוריתמים עיקריים)
- 15.2 use case לכל פונקציה עיקרית
- 15.3 מבני נתונים (PieceManager, dict, set, deque, ThreadPoolExecutor task queue)
- 15.4 חישוב יעילות אלגוריתמים (rarest-first, Tit-for-Tat, complexity analysis)
- 15.5 הקשרים בין היחידות השונות
- 15.6 עץ מודולים (Module Tree)
- 15.7 Use Case Diagram
- 15.8 רשימת Use Cases
- 15.9 תרשים UML
- 15.10 Design Class Diagram
- 15.11 תרשים מחלקות
- 15.12 תיאור המחלקות המוצעות (קלטים, פלטים, זרימת מידע בין יחידות)

### פרק 16 – תרשים מסכים (Screen Flow Diagram)
היררכיית המסכים: חלון ראשי → File Chooser → Folder Chooser → History Dialog → Algorithm Stats Dialog → Popups (Completion, Errors).

### פרק 17 – עבור כל מסך באפליקציה
- 17.1 תפקיד המסך
- 17.2 תיאור המסך
- 17.3 צילום מסך

### פרק 18 – תיאור אלמנטי תצוגה
כפתורי toolbar, תיבות בחירה לאלגוריתמים, עמודות הטבלה (כולל progress bar renderer), pane log, גרפי שורה ב-Algorithm Stats.

### פרק 19 – הודעות למשתמש (Alerts)
JOptionPane dialogs: שגיאת חיבור לשרת, שגיאת קובץ torrent, סיום הורדה (Completed popup עם נתיב), אישור ביטול, אישור ניקוי היסטוריה.

### פרק 20 – ממשק משתמש
תיאור הוליסטי: ארגון, הלימה ל-UX standards, hot keys, נגישות, RTL Hebrew.

### פרק 21 – קוד התוכנית
- 21.1 קלט (קבצי .torrent, אינטראקציה GUI, REST API, רשת)
- 21.2 פלט (קבצים שהורדו, JSON state, history.db, GUI display, logs)
- 21.3 פונקציות קריטיות/חשובות/עיקריות (`_download_loop`, `select_piece_rarest_first`, `_choke_loop`, `verify_piece`)

### פרק 22 – תיאור מסד הנתונים
- DSD: מבנה לוגי של JSON state files ושל history.db
- ERD: ישויות וטבלאות SQLite (torrents, performance_stats, algorithm_stats, events)
- לכל טבלה: עמודות, טיפוסים, מפתחות (ראשי/זר), nullability, אינדקסים, הסבר על שימוש (views/stored procedures אם רלוונטי)

### פרק 23 – מדריך למשתמש
התקנה (one-click vs manual), הוספת torrent, בחירת תיקיית הורדה, ניהול הורדות (pause/resume/cancel), צפייה בהיסטוריה ובסטטיסטיקות אלגוריתמים, פתרון תקלות.

### פרק 24 – בדיקות והערכה
- בדיקות יחידה (pytest) – לכל מודול
- בדיקות אינטגרציה (Python ↔ Java דרך REST)
- בדיקות מערכת (E2E: הורדה מלאה)
- בדיקות ביצועים (השוואת rarest-first vs random, Tit-for-Tat vs round-robin)
- ניתוח באג ההתקעות שנפתר (`DOWNLOAD_STALLING_DEBUG_GUIDE.md`)

### פרק 25 – מסקנות
מה הוכח, מה הופתעתי לגלות, איזה דברים עבדו / לא עבדו כצפוי, מסקנות הנדסיות לגבי P2P, asyncio, חצייה בין שפות.

### פרק 26 – פיתוחים עתידיים
DHT, BEP-2 (UDP tracker), Peer Exchange (PEX), Protocol Encryption, multi-file torrents, BitTorrent v2 (SHA-256), TLS/QUIC, NAT traversal, ML adaptive choking.

### פרק 27 – ביבליוגרפיה
ציטוטים מלאים בפורמט אקדמי (IEEE/APA) של 6+ המאמרים המוזכרים בהצעה + מסמכי BEP + מקורות אונליין.

### נספח א' – קטעי קוד מרכזיים
