# ספר הפרויקט – `Project_Gal_Book.docx`

ספר הפרויקט המלא, מוכן להגשה. הקובץ מתקמפל אוטומטית מתוך
קבצי ה-Markdown שבתיקיית `book/` ע"י הסקריפט `build-book.sh`.

## תכולה

- **דף שער** עם פרטי הסטודנט.
- **תוכן עניינים** סטטי (28 רשומות) — מוצג מיד אחרי דף השער.
- **27 פרקים** לפי המחוון, מופרדים בעמוד חדש.
- **נספח א'** עם 17 קטעי קוד מרכזיים מהמערכת — **כל קטע
  הוא מילה במילה מקובץ המקור** (download_manager.py,
  piece_manager.py, peer_connection.py, security.py,
  tracker_client.py, torrent_metadata.py, bencode.py,
  api_server.py, וכן ApiService.java, TorrentClientGUI.java).

## מאפייני העיצוב

- **פונט**: David בגודל 12pt לכל הטקסט.
- **RTL** לטקסט בעברית, **LTR** לקטעי קוד באנגלית.
- **קטעי קוד**: רקע אפור בהיר (#EAEAEA), פונט Consolas
  בגודל 10pt, גבול אפור בצד.
- **טבלאות**: גבולות שחורים סביב; שורת הכותרת ברקע כחול
  בהיר (#DCE6F1) ובטקסט מודגש.
- **Header** בכל עמוד: שם הסטודנט + שם הפרויקט.
- **Footer** בכל עמוד: מספר עמוד.

## פתיחה ב-Google Docs

הקובץ עבר התאמות מיוחדות ל-Google Docs:

1. **אין סימני bookmark**: כל ה-bookmarks שפנדוק יוצר באופן
   אוטומטי הוסרו, כך שלא תראה את אייקוני הסרט הכחולים
   שמסיחים את הדעת.
2. **תוכן עניינים סטטי**: התוכן עניינים מוצג כרשימה רגילה,
   לא כשדה Word דינמי (שלא היה מתעדכן ב-Google Docs ממילא).
3. **כל הסגנונות**: התאמות RTL, LTR לקוד, רקע, גבולות —
   הכל אמור להופיע נכון.

לפתיחה: גוגל דרייב → הקלקה ימנית על `Project_Gal_Book.docx`
→ Open with → Google Docs.

## בנייה מחדש

```bash
./build-book.sh
```

הסקריפט מבצע:
1. רכבת ה-Markdown של 29 הקבצים (cover + 27 פרקים + appendix)
   לקובץ אחד, עם page-break בין כל פרק.
2. הרצת pandoc → docx עם `book/reference.docx` כתבנית
   עיצוב.
3. Post-processing ב-Python:
   - הוספת `<w:headerReference>` ו-`<w:footerReference>`.
   - כפיית LTR על כל קטעי הקוד.
   - הסרת כל ה-bookmarks.
   - הוספת גבולות לכל הטבלאות.
   - שורת כותרת בצבע כחול בהיר עם טקסט מודגש.

דרישות: `pandoc` 2.x+, `python3`, `zip`/`unzip`.
