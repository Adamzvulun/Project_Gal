# Project Gal — Compiled Book (docs/)

תיקייה זו מכילה את **ספר הפרויקט המאוחד** כקובץ Word
(`.docx`), שנוצר אוטומטית מתוך 28 קבצי ה-Markdown בתיקיית
`book/` ע"י pandoc.

## הקבצים

- **`Project_Gal_Book.docx`** — ספר הפרויקט המלא (כריכה +
  תוכן עניינים + 27 פרקים + נספח א'), מעוצב על פי דרישות
  הנוהל (עמ' 9): פונט David בגודל 12, RTL, header עם שם
  הסטודנט ושם הפרויקט, footer עם מספר עמוד, ותוכן עניינים
  אוטומטי.

## עדכון תוכן העניינים בעת פתיחה

כשפותחים את הקובץ ב-Word בפעם הראשונה, **תוכן העניינים יציג
את הכותרות הריקות**. כדי לעדכן אותו:

1. ב-Word: `Ctrl+A` (לבחור הכל) → `F9` (Update Field).
2. בחלון שנפתח: `Update entire table` → OK.
3. תוכן העניינים יתמלא בכל הכותרות ובמספרי העמודים שלהן.

לחלופין: לחיצה ימנית על TOC → `Update Field` → `Update
entire table`.

## בנייה מחדש

לבנייה מחדש (אחרי שינוי קובץ Markdown), הריצו:

```bash
./build-book.sh   # מהשורש של הריפו
```

הסקריפט מבצע:
1. הרכבת כל פרקי ה-`book/` בסדר 00–27 + appendix לקובץ
   ביניים יחיד.
2. הוספת page breaks בין פרקים (raw OpenXML).
3. הפעלת pandoc → docx עם `book/reference.docx` כתבנית
   עיצוב (David font, RTL, lang=he).
4. Post-processing של ה-docx ע"י Python — הוספת ה-
   `headerReference`/`footerReference` ל-`sectPr` (pandoc
   משמיט אותם בעת ייצור הקובץ).

## דרישות מערכת

- **pandoc** 2.x+ (נבנה עם 3.1.3).
- **Python 3** (לפוסט-פרוססינג של ה-docx).
- **zip / unzip**.

## פעולות אחרונות שיש לבצע ידנית (לפני הגשה)

לפי הנוהל (עמ' 9):

1. **דף שער עם לוגו** — לפתוח את `Project_Gal_Book.docx`,
   לעבור לעמוד הראשון, ולהוסיף את לוגו המכללה במקום מתאים
   (כעת הוא ריק).
2. **תוכן עניינים** — לעדכן את ה-TOC (כפי שהוסבר למעלה).
3. **קובץ הצעת הפרויקט החתום** — להטמיע (`Insert > Object`)
   את הקובץ `הצעת פרוייקט - אדם זבולון 329441273 V2.2.pdf`
   בתוך פרק 1, כפי שדורש Fig-01 ב-`book/IMAGES.md`.
4. **30 התרשימים** — Fig-02 עד Fig-30 (תרשימים, צילומי
   מסך, ERD/DSD) — ליצור ולהטמיע במיקומים שצוינו ב-
   `book/IMAGES.md` (כל פריט עם מפרט שרטוט מפורט).
5. **תאריך הגשה** — להחליף את `___/___/2026` בדף השער.
6. **חתימות** — אם נדרשת חתימה ידנית של הסטודנט/המנחה,
   להוסיף בעת ההגשה.
